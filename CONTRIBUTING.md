# Contributing to Demo Clinic — Landing + AI Chatbot Demo

## How to run it

```bash
npx serve .
# then open http://localhost:3000
```

Or double-click `index.html`.

## What to include in a pull request

- What changed, why it changed, and how you tested it.
- Keep the change small and focused — one fix or feature per PR.
- Keep verified facts in `data/business-facts.json` and `index.html` in sync.

## What never goes in a PR

- Pricing, proposed charges, or monthly fees.
- Personal data: personal emails, personal phone numbers, home addresses.
- API keys, passwords, or `.env` files.
- Unverified claims: no invented prices, discounts, qualifications, reviews, or services. Fees stay `[TBC]` until the clinic confirms them in writing.
